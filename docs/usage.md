# 按键与提醒

从 Mac 的桥接终端输入任务。开发板约每秒更新任务状态，完整输出保留在 Mac 终端。Qoder 请求工具权限时，按终端提示选择。

| 操作 | 结果 |
| --- | --- |
| 任务运行时短按 **A** | 请求中断当前回合。已完成的文件修改会保留。 |
| 屏幕显示 `PAUSED` 后短按 **A** | 在同一个 Qoder 会话中继续。 |
| 长按 **B**，等到 `RECORDING` 再说话 | 松开后由 Mac 本地转写。[语音配置](voice.md) |
| 语音草稿显示时短按 **A** 或 **B** | **A** 发送，**B** 丢弃。任务运行时先按 **A** 暂停，再按 **A** 发送。 |

任务完成时响短音，错误或已连接后的断线响长音。震动需要外接带驱动的模块。确认模块与供电适配后，在固件里设置 `VibratorPin` 并重新烧录。[StickS3 硬件规格](https://docs.m5stack.com/en/core/StickS3)
